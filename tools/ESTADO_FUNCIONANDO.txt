FIACAO (comprovada)
----------------------------------------------------------------------
ST7789        ESP32-S3
SCL (CLK)  -> GPIO 42
SDA (MOSI) -> GPIO 41
DC         -> GPIO 38
RES (RST)  -> GPIO 37
CS         -> (nao ligado; modulo tem CS interno)
BLK        -> GPIO 8 (ou 3V3)
VCC        -> 3V3   GND -> GND

----------------------------------------------------------------------
PROTOCOLO WEBSOCKET (ESP <- servidor)
----------------------------------------------------------------------
byte[0] = 0x00 -> manifest JSON {width,height,format:"rgb565le",fps}
byte[0] = 0x03 -> chunk: [0x03][off0][off1][off2][off3][dados...]
                 offset 32-bit little-endian
                 chunk = 8192 bytes
                 O ESP monta no frameBuf; desenha quando off+n >= total

!!! PITFALL CRITICO: offset PRECISA de 4 bytes !!!
O frame tem 115200 bytes > 65535. Com offset de 2 bytes ele estourava
e voltava pra 0 a partir do chunk #9 -> frame embaralhado -> tela preta.

----------------------------------------------------------------------
PITFALLS APRENDIDOS (todos custaram tempo)
----------------------------------------------------------------------
1. Adafruit_ST7789(cs,dc,mosi,sclk,rst) => SOFTWARE SPI (bit-bang)!
   SEMPRE usar Adafruit_ST7789(&SPI, cs, dc, rst) => HARDWARE SPI.
   (bit-bang dava 1687ms/frame; hardware deu 126ms; 60MHz melhor ainda)

2. WebSockets.h da lib Markus Sattler define WEBSOCKETS_MAX_DATA_SIZE
   (15*1024) SEM #ifndef -> sobrescreve o define do sketch. Corrigido
   localmente adicionando #ifndef. (Com chunks de 8KB o default 15KB
   ja basta, mas o header estava forcando.)

3. Puppeteer headless + swiftshader = 95% CPU. headless:false usa a GPU.

4. Cesium credits/watermark: esconder via addStyleTag com
   #cesium-credits, .cesium-credit-* { display:none }.

5. View do God's Eye via postMessage {type:'gev:view', id, view}
   view = { camera:{lat,lon,altitude_m,heading_deg,pitch_deg},
            layers:[], style, map, follow }
   layers vazio = nenhum data layer (globo limpo).

6. TFT_eSPI trava no tft.init() no core esp32 3.x (registradores SPI
   crus incompativeis). Por isso usamos Adafruit.

7. Build cache do IDE as vezes nao detecta mudancas -> Sketch > Clean
   Build Folder.

8. Compilacao travada no IDE = arduino-cli.exe orfao segurando lock
   (matar o processo arduino-cli.exe).
