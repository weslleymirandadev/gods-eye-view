# God's Eye no ESP32-S3 (ST7789)

Renderiza o [God's Eye View](https://github.com/weslleymirandadev/gods-eye-view) — um globo 3D com
aviões, navios e satélites ao vivo — num display **ST7789 240x240** ligado a um **ESP32-S3**,
em tempo real via WiFi, **com controle por voz** (INMP441): fale e o globo navega.

```
[God's Eye View / Cesium]                  (navegador, GPU)
        │  Puppeteer HEADED — viewport 240x240, ?embed=1 (sem HUD)
        ▼
[esp-capture-server.cjs]                   (Node, no PC, :8082)
        │  screenshot JPEG (~10 KB/frame) @ ~18 fps
        │  fragmenta em chunks de 8 KB
        ▼  WebSocket :8082
[ESP32-S3]  decode JPEG em hardware (9 ms) → drawRGBBitmap
        ▼
[ST7789 240x240]                           (~15 fps)

VOZ (ida e volta):
[INMP441] → I2S → ESP32 → WS :8083 → [voice-server.cjs]
                                        │ faster-whisper (STT local)
                                        │ OpenRouter free (function calling)
                                        ▼ POST /action → capture-server
                                     o globo se move → captura → display
```

O frame vai como **JPEG** (~10 KB) em vez de RGB565 cru (115 KB) — 11× menos rede — e o
ESP32-S3 decodifica em **hardware**, o que viabiliza tempo real via WiFi.

## Rodar

Precisa de 3 processos no PC + o firmware no ESP.

```bash
# 1) O app do God's Eye (Vite)
npm install
npx vite                       # sobe em http://localhost:4173

# 2) Servidor de video (abre uma janela do Chrome com o globo — NAO FECHAR)
node tools/esp-capture-server.cjs --port 8082 --size 240

# 3) Servidor de voz (STT + IA). Primeira run baixa o modelo whisper (~500MB)
node tools/voice-server.cjs --port 8083
```

Depois flasha `firmware/gods-eye/` (Arduino IDE).

### Rota de teste da voz

`http://localhost:8083/mic` — pagina com os **ultimos 5 audios**, player e transcricao.
`GET /mic.json` retorna a lista; `GET /mic/audio/:id` o WAV.
Segura o botao no ESP, fala, solta: a transcricao aparece e (se for um comando) o globo se move.

### Opções do capture-server

```
--port 8082         porta do WebSocket (deve bater com o ESP)
--size 240          viewport quadrado (ex: 240, 480)
--skip 1            envia 1 a cada N frames (alivia a rede)
--lat 20 --lon -30  camera (latitude/longitude)
--alt 20000000      altitude da camera (m)
--layers flights,ais-live-vessels,satellites   camadas de dados (vazio = nenhuma)
```

## Hardware

| ST7789 | ESP32-S3 |
|--------|----------|
| SCL (CLK) | GPIO 42 |
| SDA (MOSI) | GPIO 41 |
| DC | GPIO 38 |
| RES (RST) | GPIO 37 |
| CS | — (não ligado; módulo tem CS interno) |
| BLK | GPIO 8 (ou 3V3) |
| VCC | 3V3 |
| GND | GND |

### INMP441 (microfone I2S)

| INMP441 | ESP32-S3 |
|---------|----------|
| SCK (BCLK) | GPIO 17 |
| WS (LRCLK) | GPIO 15 |
| SD (DIN) | GPIO 16 |
| L/R | GND |
| VDD | 3V3 |
| GND | GND |

**Botão (push-to-talk):** GPIO 36 → GND (`INPUT_PULLUP`; apertado = LOW).

### Config do Arduino IDE

| Opção | Valor |
|-------|-------|
| Board | ESP32S3 Dev Module |
| Flash Size | 16MB (128Mb) |
| Flash Mode | QIO 80MHz |
| Partition Scheme | Default |
| **PSRAM** | **Disabled** |
| CPU Freq | 240MHz |

> **PSRAM deve ficar Disabled.** Com `PSRAM=OPI` o WiFi entra em loop de watchdog
> (`TG1WDT_SYS_RST`) nesta placa. O firmware não precisa de PSRAM.

## Protocolo WebSocket (HTTP :8082)

```
byte[0] = 0x00 -> manifest JSON {width,height,format:"jpeg",fps}
byte[0] = 0x03 -> chunk: [0x03][total0..3][off0..3][dados...]
                  total e off = 32-bit little-endian
                  chunk = 8192 bytes
```

O ESP monta o JPEG no `jpgBuf` e, quando `off + n >= total`, decodifica e desenha.

## Pitfalls (todos custaram tempo)

- **Decoder JPEG exige buffer de saída alinhado a 16 bytes** → usar `jpeg_calloc_align(n, 16)`.
- **Offset de chunk precisa de 4 bytes.** 115200 > 65535; com 2 bytes o offset estourava.
- **`Adafruit_ST7789(cs, dc, mosi, sclk, rst)` é SOFTWARE SPI** (bit-bang, ~600× mais lento).
  Usar `Adafruit_ST7789(&SPI, cs, dc, rst)` = hardware SPI.
- **`WebSockets.h` define `WEBSOCKETS_MAX_DATA_SIZE` sem `#ifndef`** — sobrescreve o do sketch.
  (Corrigido localmente; com chunks de 8 KB o default de 15 KB já basta.)
- **Puppeteer headless + swiftshader = 95% CPU.** `headless:false` usa a GPU real.
- **Créditos do Cesium:** esconder via CSS (`#cesium-credits`, `.cesium-credit-*`).
- **`esp_lcd` (DMA) distorce pixels** nesta placa/config — não usar. O caminho é Adafruit + JPEG.
